# Portfolio Website - Bagas Aji Rasendria

Website portfolio personal untuk memamerkan skills dan project sebagai programmer pemula.

## 🚀 Demo

Website ini dibuat sebagai bagian dari challenge Study Jam 1 GDGoC UB Web Development.

## 📋 Fitur

- **Home Page**: Hero section dengan typing effect dan skill showcase
- **About Page**: Informasi tentang pendidikan dan perjalanan belajar
- **Contact Page**: Form kontak dan social media links
- **Responsive Design**: Tampilan optimal di berbagai ukuran layar
- **Interactive Elements**: Animasi dan efek interaktif menggunakan JavaScript

## 🛠️ Teknologi

- HTML5
- CSS3 (dengan custom properties & animations)
- JavaScript (Vanilla JS, tanpa framework)

## 📂 Struktur File

```
├── home.html          # Halaman utama
├── about.html         # Halaman tentang saya
├── contact.html       # Halaman kontak
├── styles.css         # Styling untuk semua halaman
├── script.js          # JavaScript untuk interaktivitas
└── README.md          # Dokumentasi project
```
